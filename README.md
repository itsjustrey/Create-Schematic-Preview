# Create: Schematic Preview

[![Modrinth Badge](https://raw.githubusercontent.com/intergrav/devins-badges/7f68fe7afdbda525557fb41097594d2edccfda03/assets/cozy/available/modrinth_vector.svg)](https://modrinth.com/mod/create-schematic-preview)
![Neoforge Badge](https://raw.githubusercontent.com/intergrav/devins-badges/7f68fe7afdbda525557fb41097594d2edccfda03/assets/cozy/supported/neoforge_vector.svg)

A Create addon that adds a 3D preview of your schematics inside the Schematic Table
![Preview](docs/preview.png)

Schematic item tooltips also support preview. Hold `Alt` while hovering a Schematic item to see it.
![Tooltip Preview](docs/preview-tooltip.gif)
